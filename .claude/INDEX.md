# Hermes Operating Framework — Org Index

> The `.claude/` operating ecosystem for building, running, and debugging Hermes.
> Generated by the Hermes Prime orchestration (specialists → Review Board → integration),
> 2026-06-15. Architecture is **Option B** (keep `hermes-agent`, route work around the
> monolithic agent loop). Grounding evidence: [docs/AUDIT.md](../docs/AUDIT.md).

## How it fits together
```
        STANDARDS  (the rules)            WORKFLOWS  (the processes)
        engineering-standards ─┐          incident-response · deploy-pipeline
        agent-authoring        ├─ govern → doc-sync · feature-dispatch
        review-checklist ──────┘                    │ run via
                                                     ▼
   COMMANDS  /bug /doctor /deploy /context /roadmap /hunt /review
                                                     │ wrap
                                                     ▼
   AGENTS (roles) ──use──► SKILLS (procedures) ──emit──► TEMPLATES (reports)
                                                     │ vetted by
                                                     ▼
                                   REVIEW BOARD (technical/security/integration)
```
